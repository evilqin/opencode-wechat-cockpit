它和别的「微信桥」不一样在哪

不是 demo 级脚本，是按「它会替我管电脑」的标准写的。

🛂

审批直达手机

agent 要执行命令被桌面端卡住？微信里收提示，回 1、/allow always 或 /deny 就放行或拒绝，不用回电脑前。

❓

提问直达手机

内置 wechat_ask 工具：agent 需要人拍板时直接问你，微信里作答即返回结果；等待期间自动保活，不会被「假死恢复」插件误打断。

🏠

手机会话有「家」

/new、/list、/attach、/switch：每个微信对话框对应一个会话，主会话永久保留，切换有明确回执。

📬

消息乱序也不丢

发送带稳定 client_id（幂等重试不重发）、队列逐条落盘、回复窗口关了就先排队、半截回答自动编号补发（1/3、2/3…）。

🔒

单轮询器 + 自愈

多个 opencode 窗口也只跑一个轮询；带锁心跳、卡死自动接管、网络看门狗（长轮询丢包自动退避重连）；卸载时只有锁持有者宣告下线。

🧪

工程级可靠性

206 个自动化测试 + strict typecheck，CI 在 Windows 与 Ubuntu 双平台全绿。真机跑了几个月的 bug 都是「审计找出来的」，不是用户踩出来的。

三步上手

前提：本机已装 opencode，且手机微信能扫码登录。

克隆到插件目录

放进 opencode 的插件目录，重启后自动加载。

装两个二维码依赖

登录二维码靠它们渲染，一次性安装。

扫码登录

会话里敲 /wechat-login，手机微信扫码，然后给这个 bot 发消息即可。

git clone https://github.com/evilqin/opencode-wechat-cockpit ~/.config/opencode/plugins/wechat
cd ~/.config/opencode/plugins/wechat && bun add qrcode qrcode-terminal
# 然后在 opencode 会话里输入：
/wechat-login

常见疑问

安全吗？凭据存哪？
凭据只写本机状态文件（POSIX 0600；Windows 走用户目录 ACL），随代码一起开源、随时可审。网络出口只允许 https 且域名白名单（连 file:// 回环都会被拒绝）。
需要公网 IP / 内网穿透吗？
不需要。本机主动长轮询腾讯 iLink 网关，家宽 / 校园网 / 公司网都能用。
会封号吗？
底层是微信 iLink 接口的非官方用法，风险自担。请只绑定自己的号、用于遥控自己的电脑，不要用于群发、营销等滥用场景——这也是此项目刻意不做「批量操作」的原因。
和那一堆「wechat 机器人」比呢？
那些多是通用聊天机器人；这个项目的定位是 opencode 的远程驾驶舱：审批、提问、会话切换、工具进度、可靠性（幂等/队列/锁/自愈）都是围绕 coding agent 设计的。
